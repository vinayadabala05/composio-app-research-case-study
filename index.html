1. The research agent

Goal: scale the research-before-toolkit workflow Composio already does by hand across hundreds of apps.

What the agent does

  • Takes a structured list of 100 apps (name + seed URL).
  • For each: finds official developer docs, auth pages, pricing / partner pages.
  • Extracts category, one-liner, auth methods, self-serve vs gated, API breadth, existing MCP, buildability + main blocker, evidence URLs.
  • Writes structured JSON and a summary matrix; runs verification on a held-out sample.

Where a human was still needed

  • Ambiguous self-serve (free trial vs contact-sales after trial)
  • Partner-only APIs with public docs that look open
  • MCP claims that are demos / unofficial
  • Final judgment on buildable today when docs are incomplete

3. Patterns across the full set

Auth dominance

OAuth2 is the default for multi-tenant SaaS. API keys remain common for developer tools and data APIs. Basic auth is mostly legacy.

Self-serve vs gated

Developer platforms, messaging, productivity, and payments are largely self-serve. Ads platforms, enterprise CRM, and some fintech/research tools require review, paid plans, or partnerships.

MCP reality

True official MCP servers are still sparse. GitHub and Linear are clear positives. Many MCP mentions are experimental or provider wrappers.

4. Verification

  • Verified sample: 20 apps with direct docs checks (see data/verified_sample.json).
  • Auth method: first pass ~85% → after loop ~95%+
  • Self-serve vs gated: first pass ~70% → after loop ~90%+ (main failure: docs look open but paid/partner-only)
  • Honest hard cases: Ahrefs (paid units), Shopify (public app review), Salesforce/Zendesk/Intercom (admin friction), MCP status noise

Accuracy is the primary metric. The agent escalates low-confidence rows instead of inventing certainty.

6. Takeaway for Composio Product Ops

The bottleneck is not finding the docs URL. It is reliably classifying self-serve vs gated and deciding whether a toolkit is buildable today without a sales conversation. An agent that does bulk extraction + confidence scoring + human-in-the-loop on the hard 20–30% already multiplies throughput. Highest-ROI next step: a living matrix of the ~40–50 clearly self-serve, well-documented apps ranked by customer request volume.
